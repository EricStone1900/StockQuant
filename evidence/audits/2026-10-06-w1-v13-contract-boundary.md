# W1 / V1.3 versioned WAITING API contract

Date: 2026-10-06. This audit freezes the currently implemented Platform-only boundary while V1.3's Governance/Trade/Portfolio/FakeBroker workflow remains unimplemented.

The new schemas define the fixed `normal`/`rejection`/`recovery` request with an integer seed in `[0, 2147483647]`, the persisted 202 response, and the owner-scoped WAITING result. The result schema requires `businessExecution=NOT_RUN`, `businessServicesCalled=[]`, all three business-fact fields `NOT_CREATED`, and `liveTradingEnabled=false`. The separate `v13-acceptance.v1` OpenAPI contract records the current Platform endpoints and their status codes. Platform rejects unknown fields/scenarios and out-of-range or non-integer seeds before persisting a TestRun.

Verification passed: `pnpm contracts:check` (JSON validation, generated-type drift, 110 compatibility rules, and OpenAPI operations); Platform API typecheck; targeted V1.3 contract/engine tests (1 file, 13 tests); and the final `pnpm verify:stage -- --stage V1.3 --suite code` with exit 0 under the controlled local-loopback test environment. It does not complete the V1.3 business workflow or change stage/human acceptance.
