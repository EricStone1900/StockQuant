## 历史上下文门禁语义核对

代码核对确认：Market Data 对已登记记录计算/比较内容Hash，检查有效期、证券覆盖、市场字段、交易时段字段及公司行动数组；`sourceReference` 与 `attestedBy` 只校验非空。它没有抓取或验证引用内容，也没有验证停牌、公司行动完整性或规则权威性。因此原 `status=READY` 是结构就绪，不是外部事实已核验。Platform 另行检查导入的 `researchUseAllowed` 和精确来源用途配置；该配置也不替代来源许可证明。

本次将 `evidenceAssurance=STRUCTURAL_CHECK_ONLY_OWNER_ATTESTATION` 加入回放就绪响应与 OpenAPI 返回合同，并将Web登记标题/说明改为“历史上下文版本（所有者声明）”，提示 `READY` 的结构检查范围及外部事实未独立核验。没有改变来源授权、数据许可或回放行为。因为本轮没有获准开启真实历史研究用途，未执行正向 Web 回放；本次未运行自动化测试；Market Data build、Web typecheck、OpenAPI 静态合同检查、Markdown 链接检查及差异空白检查通过。

## 收口决定

1. 把样本期 MarketRuleSet 标为**部分已映射**，并将用途限制为 Bar 日内时段/覆盖分析；该部分映射不满足完整撮合回放的规则前置。
2. 将跨频差异从“待消除/待核清的本地质量错误”改记为“Provider 可复现差异，原因未明、频率语义未证实”。保留 RAW 原文与单位，禁止修写、重缩放或调整容差以强行相等。
3. 本次 BaoStock 一次性 20 RPC 额度已用尽，不再调用该数据端点。没有逐分钟停牌事实、全类型公司行动覆盖或数据许可结论，因此不登记一套宣称完整/权威的真实历史上下文，不执行正向研究回放。
4. C3 剩余工作聚焦到原门禁：明确将部分规则和来源限制写进导入/运行证据；若现有完整历史上下文检查会把“非空引用+操作者 attestation”误当事实完整，修正该边界；在明确允许的本地学习用途与来源配置前置满足后，再做一次正向 Web 导入→读取→回放→同 Run 证据。人工验收仍需绑定当前候选。

验证边界：本记录使用上交所官方规则网页/公告与已批准的 BaoStock 小样本；未执行规则附件全文逐条版本差异审计、证券级停牌/公司行动补查、模型训练或回放，也未修改原始数据。来源查询预算和原始响应留存期限见[有界来源补证记录](./2026-10-22-v22-historical-source-probe.md)。
