# Web应用与开发验收中心架构

状态：设计/NOT_RUN。目标目录apps/web，React/TypeScript；对应[平台API](../services/platform-api-service.md)。V1.1起每阶段同步交付。

## 1. 页面与模块

正式页面按业务划分账户、数据/新闻/股票池、策略/模型、回测/回放、建议/授权、订单/成交/对账、研究及运行总览。统一/acceptance入口按版本/阶段/场景导航，保留历史运行、证据和人工记录；正式页面与测试页共享组件/API。

目标模块：app/router与身份守卫、features各业务功能、acceptance场景/运行/证据、generated-client、ui通用状态与金额/时间展示。前端不计算权威账本或自行推进订单状态；前端输入校验方便用户，服务端仍完整校验。

## 2. 数据与权限

浏览器只访问平台API/受控下载入口，不直接连DB、NATS、Temporal或Docker。服务器确认身份、account/market/mode/run范围；按钮隐藏不等于权限控制。读模型展示asOf/版本/质量，写操作带expectedVersion和稳定幂等键，重复提交不得创建第二笔业务。

页面查询缓存按账户/run/版本分区；切换账户清除不适用状态。真实密钥不写前端存储或错误页，生成代码/新闻仅作为转义的不可信内容展示。会话失效和403明确提示，不当作正常空数据。

## 3. TestRun交互

选阶段/场景→展示前置能力和固定输入→准备独立运行→调用业务流程→查询后台状态→显示expected/actual断言→跳转正式页核对→导出证据→用户追加人工结论。场景初始化业务本身被测时不能提前绕过初始化。

normal/rejection/recovery与CLI使用相同版本定义，check-only只读已有run并追加检查证据，不创建订单/模型调用。TestRun执行、自动断言、人工结论分开；202、COMPLETED不等于人工PASS。手册VERIFIED_EXECUTABLE只表示实测可执行。

## 4. 长任务与恢复

后台拥有运行生命周期，浏览器轮询或订阅只展示，关闭/刷新后用runId恢复。Web展示QUEUED/RUNNING/WAITING/CANCELLING/COMPLETED/FAILED/CANCELLED；过期/局部失败保留原因和历史证据。

研究取消、回放暂停、执行暂停/撤单分开按钮和说明。撤单请求不能立即显示CANCELLED，合法在途Fill仍更新。外部进程重启/断网由限定脚本或人工操作，Web只给步骤和证据收集。

## 5. 证据、待办与清理

每阶段第7/8节对应Web任务/步骤、实际URL、输入、预期和命令。展示代码/镜像/规则/数据/seed/故障序列、Trace/业务ID、截图/断言与未覆盖范围。人工记录追加到平台，不自动代签、不覆盖失败。

新测试创建独立namespace。清理展示精确目标，拒绝活动或权限外运行，默认保留证据；无全库重置、任意SQL/shell按钮。证据下载脱敏且防跨run访问。

## 6. 验证

T35/36、VT01及各阶段浏览器E2E：加载/空/错/403/陈旧/冲突/部分成功、金额/时区、键盘操作、真实API、关页继续、同run CLI核对和不能自动人工签署。不能以纯JSON或动画替代可操作正式功能。全部状态NOT_RUN。
