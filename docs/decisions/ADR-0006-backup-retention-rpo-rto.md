# ADR-0006 备份位置、保留期与 RPO/RTO

状态：Accepted；日期：2026-09-19。关联：PRD Q11、V2/V3 发布验收。

## 决策

- PostgreSQL 逻辑备份写入部署主机的 `STOCKQUANT_BACKUP_DIR`；未配置时使用 `/var/lib/stockquant/backups`。备份目录不提交 Git，并通过主机快照或异地复制保护。
- 每日全量、每小时增量（若部署平台支持）；保留 30 个自然日，月末备份保留 12 个月。备份带 SHA-256 与生成时间，恢复到隔离数据库后才能标记可用。
- 目标 RPO ≤ 24 小时，目标 RTO ≤ 4 小时。未完成隔离恢复演练前，发布验收不得声称达到目标。
- 恢复顺序为停止写入、校验清单、隔离库恢复、表/行数与就绪检查、切换连接，并保留原库只读证据。

验证使用 `scripts/dc07-verify-deployment.mjs`；实际生产位置、快照和异地复制由部署环境配置，不能用 Fixture 代替。
