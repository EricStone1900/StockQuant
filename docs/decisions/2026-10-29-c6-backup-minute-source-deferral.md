# C6 备用分钟源延期决定

日期：2026-10-29。状态：`ACCEPTED`。批准人：项目所有者（当前会话）。

所有者询问“暂时不要备用分钟源可不可以？”，并在收到延期建议后明确回复“按照你的建议执行”。据此，将C6本轮本地学习收口中的第二分钟源接入及其逐证券60个交易日覆盖标记为`DEFERRED`；该项不再阻塞本轮单源范围收口。停止继续寻找、注册、接入或探测备用分钟源；已有适配器、历史证据及失败记录保留。未指定恢复日期，不创建提醒或后台任务。

本轮复用已有BaoStock冻结归档及其受限软件验证证据，优先核对导入、版本化查询、持久任务排队、取消、恢复、配额和正式Web/同Run CLI衔接。来源不可用、输入缺失或覆盖不足时，暂停依赖该输入的任务并记录原因，不自动切换来源或补造OHLCV。实现与验证顺序仍维护在[V2主计划§7.2.3](../prd/v2-data-and-replay/00-version-plan.md#723-c6单源范围接续2026-10-29)。

本决定仅延期备用分钟源，不取消全市场分钟容量、真实来源长期稳定性、PIT/研究及V2.4实际观察的原缺项，不改变已有归档的用途/许可/留存边界，也不批准新的外部采集、模型训练、活动策略、真实券商或LIVE。恢复备用源时，先重新记录精确来源、端点、适用条款、预算、留存及独立覆盖证据。

这是范围调整批准，不是C6功能验收或人工签收。C6仍未完成；原完整V2.5及V2门禁保持未通过。后续只有本轮适用主功能、必要验证、可执行手册与当前候选人工签收完成，才可报告对应单源范围完成；延期项永不计入测试PASS。
